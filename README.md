# HoraClick — downloads

Recupera a data e a hora originais de fotos e vídeos (EXIF, RAW, XMP, metadados de vídeo) e grava o carimbo na imagem.

Este repositório contém **somente os instaladores**. Baixe a versão mais recente em
**[Releases](../../releases/latest)**:

- **Android 10+:** `HoraClick-<versão>-android-arm64.apk` (quase todos os celulares) ou `-universal.apk`.
- **Windows 10/11:** `HoraClick-Setup-<versão>.exe`.

Quem já tem o app instalado recebe as novas versões automaticamente.
